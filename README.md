# Exercises

1. Create a Numpy array that holds time data. Make it such that you have 100 timesteps (distributed linearly) ranging from 0 to 1 seconds. Store it in a variable.
    - Hint, you can use: numpy.arange() or numpy.linspace()

1. Create a Numpy array that holds sinusoidal data, with an amplitude of 1 and a frequency of 1 Hz. Make it such that it has as much data as the previously made time data. Store it in a variable.
   - Hint, you can use: a for loop or list comprehension, combined with numpy.sin()

1. Use the timesteps and the sinusoidal data to create a two dimensional graph, using Matplotlib.
   - Do not forget to decorate the plot correctly (title, labels, etc.)

1. Create a Numpy array that holds sinusoidal data, with an amplitude of 0.5 and a frequency of 3 Hz. Make it such that it has as much data as the time data. Store it in a variable.

1. Combine (by summation) the two sinusoidal signals you have made. Plot the result.
